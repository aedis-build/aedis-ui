# aedis-ui

[Aedis UI](https://ui.aedis.build) components are source code you add to your app with the `aedis` command; this package is that command, the same as [`@aedis/cli`](https://www.npmjs.com/package/@aedis/cli), under the name of the library. It depends on the exact `@aedis/cli` version it was released with. Prefer `@aedis/cli` directly:

```bash
npx @aedis/cli@0.6.0 add button
```

Never run `npx aedis`: the unscoped `aedis` package on npm is not ours. `aedis-cli`, `aedis-ui` and `create-aedis` are.

Source and security policy: [github.com/aedis-build/aedis-ui](https://github.com/aedis-build/aedis-ui). Apache-2.0.
